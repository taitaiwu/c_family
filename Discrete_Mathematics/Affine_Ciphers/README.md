# 仿射密碼(Affine Ciphers)的加、解密程式 (正確程式評分區間：70~80)

## 題目說明
仿射密碼的加密函數具有 $f(p) = (ap + b)\ mod\ 26$ 的形式，仿射密碼的詳細說明請參閱課本第四章第六節的說明，此題要求同學撰寫仿射密碼的加、解密程式。

* **加密程式輸入說明：**
    加密程式輸入檔(affine-encode-in.txt)的第一行有兩個以空白相隔的整數代表仿射密碼的加密金鑰 a 跟 b，第二行則為須加密的英文字母串。若仍有後續的輸入資料，格式同上述的第一、二行。

* **加密程式輸出說明：**
    依序印出加密後的訊息於輸出檔(affine-encode-out.txt)中，每一行代表一個獨立的加密結果。

* **加密程式範例輸入：**
    ```
    7 3
    K
    ```

* **加密程式範例輸出：**
    ```
    21
    ```

* **解密程式輸入說明：**
    解密程式輸入檔(affine-decode-in.txt)的第一行有兩個以空白相隔的整數代表仿射密碼的加密金鑰 a 跟 b，第二行則為須解密的英文字母串，請注意你的程式需根據加密金鑰 a 跟 b 算出解密金鑰 ā 以便解密。若仍有後續的輸入資料，格式同上述的第一、二行。

* **解密程式輸出說明：**
    依序印出解密後的訊息於輸出檔(affine-decode-out.txt)中，每一行代表一個獨立的解密結果。。

* **解密程式範例輸入：**
    ```
    7 3
    21
    ```

* **解密程式範例輸出：**
    ```
    K
    ```
