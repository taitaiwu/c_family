2. **RSA 密碼系統的加、解密程式 (正確程式評分區間：90~100)**
    RSA 密碼系統是一種非對稱的密碼系統，亦即加密公鑰跟解密私鑰並不相同，其加密公鑰具有($n$, $e$)的形式，其中 $n=pq$ 為兩個很大質數的乘積，而 $e$ 則為與$(p−1)(q−1)$ 互質的整數。假設我們要加密的訊息由大寫英文字母組成，A 的代碼為 00、B 的代碼為 01、…餘此類推。加密時我們將所有英文字母的代碼串接起來，然後選擇一個適當的加密區塊長度，將整個訊息 M 依區塊長度切割成一連串的整數 $m_1,m_2,…,m_k$，每個區塊 $m_i$ 的加密方式為 $c_i = m_ie\ mod\ n$，其中 $c_i$ 為加密後的區塊，mod 為兩數相除後取餘數的模運算，例如 8 mod 3 = 2。在上述的系統中若我們要以公鑰(2537, 13)加密 STOP 這個訊息，其中 2537 = 43×59，STOP的代碼為 18191415，加密區塊長度為 4，因為 181913 mod 2537 = 2081 且 141513mod 2537 = 2182，所以加密後的訊息為 20812182。而解密私鑰 $d$ 是 $e\ mod\ (p−1)(q−1)$的反元素，亦即 $de\ mod\ (p−1)(q−1)=1$，解密的方法為 $m_i = c_id\ mod\ n$。在上述的系統及公鑰(2537, 13)不變的狀況下，私鑰 $d$ 為 937，因為(937×13) mod(43−1)(59−1) =1，若接收的密文是 09810461，依解密方法運算 0981937 mod 2537= 0704 且 0461937 mod 2537 = 1115，所以解密過後的訊息為 07041115，此代碼轉換英文訊息為 HELP。
    
    * **加密程式輸入說明：**
        輸入檔(RSA-encode-in.txt)的第一行代表公鑰的兩個數字 `n e`，數字間以空白相隔；第二行是加密區塊長度；第三行則為須加密的英文字母串。若仍有後續的輸入資料，格式同上述的第一至第三行。加密程式輸出說明：依序印出加密後的數字串於輸出檔(RSA-encode-out.txt)中。
    
    * **加密程式範例輸入：**
        ```
        2537 13
        4
        HELP
        ```

    * **加密程式範例輸出：**
        ```
        09810461
        ```

    * **解密程式輸入說明：**
    解密程式輸入檔(RSA-decode-in.txt)的第一行為代表公鑰的三個數字 `p q e` 數字間以空白相隔；第二行是加密區塊長度(測資最大加密區塊長度為 18)； 第三行是接收到的密文代碼，密文代碼長度會是加密區塊長度的倍數。若 仍有後續的輸入資料，格式同上述的第一至第三行。

    * **解密程式輸出說明：**
        依序印出解密後的訊息於輸出檔(RSA-decode-out.txt)中，每一行代表一個獨立的解密結果。

    * **解密程式範例輸入：**
        ```
        43 59 13
        4
        09810461
        ```

    * 解密程式範例輸出：
        ```
        HELP
        ```
