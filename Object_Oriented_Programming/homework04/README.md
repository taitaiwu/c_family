# Homework4 - Joe’s Automotive Shop

Joe’s Automotive Shop provides maintenance and repair services for foreign cars, with a particular specialization in brands such as Mercedes, Porsche, and BMW. When a customer brings a vehicle to the shop, the manager collects the customer’s personal information, including name, address, and telephone number. The manager also records the vehicle’s details, such as make, model, and year.

Based on the vehicle’s condition and required service, the manager prepares a service quote. This quote includes estimated parts charges, estimated labor charges, applicable sales tax, and the total estimated cost. The service quote serves as an important record of the transaction and is used for both customer reference and internal management.

The system should model key elements of the problem domain, including physical objects (vehicles), human roles (manager and customer), and business records (service quotes). In addition, the system must support record management functionalities.

Specifically, the manager should be able to:
* Create and store new service quotes
* Search for service quotes using either the customer’s name or the quote date as keywords
* Display all service quotes that match the search criteria
* Delete existing service quotes when necessary

The system should be implemented as an object-based program, with appropriate class design to represent customers, vehicles, service quotes, and management operations. The design should emphasize modularity, clarity, and ease of maintenance.

Furthermore, a user manual should be provided to explain how to operate the program, including descriptions of all available functions. Any additional or advanced features should also be clearly documented.
